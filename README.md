# Runner's Quest

**Runner's Quest** é um projeto universitário desenvolvido como parte dos meus estudos. Este jogo de plataforma foi criado com **Python** e **Pygame**, oferecendo uma experiência divertida e acessível para todos os jogadores.

---

## 🎮 Sobre o Jogo
- **Objetivo:** Controle seu personagem enquanto supera obstáculos e acumula pontos.
- **Desafio:** A dificuldade aumenta à medida que você avança, tornando cada partida única.
- **Imersão:** Música e efeitos sonoros acompanham o ritmo dinâmico do jogo.

---

## 📚 Propósito Acadêmico
Este projeto foi desenvolvido com os seguintes objetivos:
- Colocar em prática conceitos de programação aprendidos no curso de faculdade.
- Explorar a criação de jogos 2D usando a biblioteca **Pygame**.
- Demonstrar habilidades técnicas e criatividade por meio de um projeto funcional.

---

## 🛠️ Tecnologias Utilizadas
- **Python:** Linguagem principal para construção do jogo e sua lógica.
- **Pygame:** Biblioteca utilizada para criação de gráficos, animações e sons.

---

## 🌟 Funcionalidades
- Tela inicial animada com texto piscante e música de fundo.
- Controle intuitivo: use o teclado para movimentar e pular.
- Sistema de pontuação dinâmico.
- Elementos visuais e sonoros que proporcionam uma experiência imersiva.

## 📥 Como Baixar e Jogar no PC
Siga as instruções abaixo para instalar e jogar **Runner's Quest** no seu computador.

### ✅ Etapa 1: Instalar o Python
Antes de começar, você precisa ter o **Python** instalado (versão 3.8 ou superior). Para isso:
1. Acesse o site oficial do Python: [python.org](https://www.python.org/downloads/).
2. Baixe a versão recomendada para seu sistema operacional (Windows, macOS ou Linux).
3. No Windows, **durante a instalação**, marque a opção **"Add Python to PATH"** antes de clicar em "Install Now".
4. Para testar se o Python foi instalado corretamente, abra o **Prompt de Comando** (Windows) ou **Terminal** (Mac/Linux) e digite:
   ```bash
   python --version
   ```
   Se aparecer algo como `Python 3.x.x`, a instalação foi bem-sucedida.

### 📥 Etapa 2: Baixe o jogo
1. Acesse o repositório do jogo no GitHub:
   [Runner's Quest - GitHub](https://github.com/stuartfsi05/runners-quest).
2. Clique no botão **Code** e escolha **Download ZIP** para baixar o projeto.
3. Extraia o conteúdo do arquivo ZIP para uma pasta de sua escolha.
   - **Dica:** Certifique-se de lembrar onde extraiu o arquivo, pois precisaremos acessar essa pasta depois.

Alternativamente, se você tem Git instalado, pode clonar o repositório executando:
```bash
git clone https://github.com/seuusuario/runners-quest.git
```

### 🔧 Etapa 3: Instale o Pygame
Agora precisamos instalar a biblioteca **Pygame**, que permite que o jogo rode corretamente.
1. Abra o **Prompt de Comando** (Windows) ou **Terminal** (Mac/Linux).
2. Digite o seguinte comando e pressione **Enter**:
   ```bash
   python -m pip install pygame
   ```
3. Aguarde a instalação ser concluída.
   - Se der erro informando que `python` não foi encontrado, tente usar `py` no lugar:
     ```bash
     py -m pip install pygame
     ```

### 🎮 Etapa 4: Rode o jogo
1. Abra o **Prompt de Comando** (Windows) ou **Terminal** (Mac/Linux).
2. Navegue até a pasta onde extraiu o jogo. Para isso, use o comando:
   ```bash
   cd caminho/para/a/pasta/runners-quest
   ```
   - Exemplo: Se a pasta está na sua Área de Trabalho, use:
     ```bash
     cd C:\Users\SeuNome\Desktop\runners-quest
     ```
3. Execute o jogo digitando:
   ```bash
   python main.py
   ```
   - Se houver erro informando que `python` não foi encontrado, tente usar `py`:
     ```bash
     py main.py
     ```

> 🎉 **Parabéns!** O jogo será iniciado e você poderá começar a jogar **Runner's Quest**.
